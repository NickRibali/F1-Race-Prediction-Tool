# F1 Race Predictor

Streamlit app that predicts F1 finishing order from a starting grid.

Run locally:  pip install -r requirements.txt  then  streamlit run app.py

Files:
- app.py: the web page
- model.py: features, training, input checks, prediction
- f1_clean.csv: cleaned race results (export from the analysis notebook)
- requirements.txt: packages Streamlit Cloud installs
